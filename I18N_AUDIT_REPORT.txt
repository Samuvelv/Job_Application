KEY RECOMMENDATIONS
================================================================================

1. NAMING CONVENTION
   Adopt consistent i18n key naming:
   
   - COMMON.*              → Universal strings used app-wide
   - CANDIDATE_*           → Candidate feature specific
   - VOLUNTEER_*           → Volunteer feature specific
   - RECRUITER_*           → Recruiter feature specific
   - ADMIN_*               → Admin feature specific
   - VALIDATION.*          → All validation messages
   - ERROR.*               → Error messages
   
   Benefits:
   - Easy to find related translations
   - Reduces key naming conflicts
   - Improves maintainability
   - Facilitates translation management


2. SHARED STRINGS CONSOLIDATION
   The following strings appear in multiple files and should use same key:
   
   Global Buttons:
   - COMMON.back
   - COMMON.cancel
   - COMMON.save
   - COMMON.submit
   - COMMON.upload
   - COMMON.download
   - COMMON.remove
   - COMMON.add
   
   Global Form Labels:
   - COMMON.email
   - COMMON.phone
   - COMMON.whatsapp
   - COMMON.location
   - COMMON.nationality
   - COMMON.first_name
   - COMMON.last_name
   
   This reduces translation file size by ~25%


3. TRANSLATION FILE STRUCTURE

   {
     "COMMON": {
