RECOMMENDATIONS FOR FIXING:
============================

APPROACH 1: Use [textContent] Binding (RECOMMENDED)
  Change: {{ candidate.bio }}
  To: <p [textContent]="candidate.bio"></p>
  
  Advantages: Simple, safe, native Angular
  Time: 30 mins per component

APPROACH 2: Use DomSanitizer (For complex content)
  constructor(private sanitizer: DomSanitizer) {}
  getSafeContent(html) { return this.sanitizer.sanitize(SecurityContext.HTML, html); }
  
  Advantages: Allows controlled HTML rendering
  Time: 1-2 hours per component

APPROACH 3: Backend Sanitization (Defense in depth)
  Sanitize user input at API level before storing
  
  Advantages: Protects multiple frontends
  Time: 4-8 hours implementation

TESTING PAYLOADS:
=================

Basic XSS:
  <img src=x onerror="alert('XSS')">
  <script>alert('XSS')</script>

Event handler:
  "><svg onload="alert('XSS')">
  '><svg onload="alert('XSS')">

Encoded:
  %3Cimg%20src%3Dx%20onerror%3D%22alert('XSS')%22%3E

Context-specific:
  javascript:alert('XSS')
  data:text/html,<script>alert('XSS')</script>
